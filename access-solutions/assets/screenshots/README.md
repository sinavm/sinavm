## روش افزودن تصویر

1. وارد مخزن `sinavm/sinavm` شوید.
2. پوشه `access-solutions/assets/screenshots` را باز کنید.
3. گزینه Add file و سپس Upload files را انتخاب کنید.
4. تصویر را با نام دقیق جدول بارگذاری کنید.
5. تغییر را روی شاخه main ثبت کنید.

فرمت پیشنهادی JPG است. اگر تصویر PNG است می‌توانید پسوند را PNG نگه دارید و مسیر همان کارت را نیز هماهنگ تغییر دهید.

هر تصویر باید متعلق به همان پست تلگرام باشد. پیش از انتشار اطلاعات شخصی یا شناسه حساس را از تصویر حذف کنید.
